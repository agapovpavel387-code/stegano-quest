How it works / privacy

Hide: the secret goes to the LLM, which returns an innocent cover prompt; the image API renders it; your message is then embedded into the pixels (LSB) entirely in your browser. Reveal: LSB is read back out. In Own Pollen mode every request is billed to the key you entered — your wallet, your expenses. The key is stored only in this browser (localStorage) and sent only to pollinations.ai endpoints.
